# One reviewed follow-up after the hosted pilot

This slice combines the decision-history presentation and rejection recovery changes, then prepares one additional owner-approved Eve request. Publishing or deploying it does not grant that request automatically.

The owner first closes the coding run after recording provider completion and refreshing GitHub evidence. A continuation review is available only after five provider attempts, with one current public-repository result independently classified as a tested draft PR, passing required checks, and fresh evidence. Active, uncertain or paused work blocks the review.

The review shows the unchanged model, cumulative spending ceiling, retained reservations, and exact completion snapshot proposed for model disclosure. Explicit approval raises the attempt limit from five to six once. It resolves only a recognized rejection whose linked recovery produced the closed coding assignment. Failure evidence and all reservations remain recorded. Unknown results and spend-cap rejections are not eligible.

Approval binds the current brief, model, accounting and evidence. It expires after fifteen minutes and is idempotent. A subsequent brief change or expired completion source blocks inference. Source freshness is checked before provider I/O and before approving any resulting commitment or coding assignment. The user submits the follow-up separately; approval itself starts no inference or coding.

Eve receives a compact, citable, owner-reviewed source containing the observed provider completion, public draft PR, exact commit, check outcomes and observation times. Raw worker reports, private traces and credentials are excluded. The source explicitly distinguishes a tested draft from a merge or deployment. Already-attempted coding candidates are omitted from new proposals.

The UI now shows a closed coding run and removes its close button after success. Current and earlier project decisions are grouped while preserving the recovery controls and prior approval guards. Broader closeout UX improvements remain separate work.

Validation: 44 root tests and source checks passed; 77 hosted/Eve tests passed; the Vercel production-output build passed. Independent review identified and verified fixes for context drift and completion-source expiry. A local synthetic browser test verified review, approval without sending, a separate follow-up citing the completion source, retained failure history, and the sixth-attempt stop. No live model call is part of this validation.

Limitations: this is one additional request, not an ongoing pilot budget or automatic follow-up. The Routines API session-ID receipt mismatch remains separate from the verified manual observation path. Review-source freshness is limited to one day; refresh result evidence before creating a stale continuation review. No automatic merge, deploy, coding dispatch or billing fallback is added.
